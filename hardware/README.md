# Suraksha Path Offline Tracking System (ESP-NOW)

This folder contains the Arduino firmware to build the offline GPS tracking hardware using two ESP8266 boards.

## 1. The Wearable Node (`Wearable_Node.ino`)
This board is carried by the tourist. It reads GPS coordinates and broadcasts them offline via ESP-NOW, bypassing the need for a mobile network.

### Hardware Required:
- 1x NodeMCU ESP8266 or Wemos D1 Mini
- 1x NEO-6M GPS Module (or similar)
- 1x Push Button (for SOS)
- A battery pack (e.g., 18650 shield)

### Wiring:
| ESP8266 Pin | Component Pin |
| ----------- | ------------- |
| `3V3` / `5V`| GPS `VCC`     |
| `GND`       | GPS `GND`     |
| `D1` (GPIO5)| GPS `TX`      |
| `D2` (GPIO4)| GPS `RX`      |
| `D3` (GPIO0)| SOS Button (Other leg to `GND`) |

---

## 2. The Gateway Node (`Gateway_Node.ino`)
This board sits at the "Base Camp" (e.g., your tent, a hotel, or a checkpost) where there is a stable WiFi connection or a mobile hotspot. It listens for offline ESP-NOW signals from tourists and forwards them to your Node.js backend.

### Hardware Required:
- 1x NodeMCU ESP8266 or Wemos D1 Mini
- Micro-USB cable for power

### Wiring:
None! Just plug it into a power source.

---

## How to Set It Up (Step-by-Step)

### Step 1: Find the Gateway's MAC Address
Before flashing the Wearable, you need to know the Gateway's MAC Address.
1. Plug in the Gateway board.
2. In Arduino IDE, open `File > Examples > ESP8266WiFi > MacAddress`.
3. Flash it, open the Serial Monitor (115200 baud), and copy the MAC Address (e.g., `A4:CF:12:34:56:78`).

### Step 2: Flash the Wearable Node
1. Open `Wearable_Node/Wearable_Node.ino` in Arduino IDE.
2. Install the `TinyGPSPlus` library via Library Manager.
3. Edit the `gatewayAddress[]` array with the MAC address you found in Step 1.
   *(Change colons to `0x`, e.g., `uint8_t gatewayAddress[] = {0xA4, 0xCF, 0x12, 0x34, 0x56, 0x78};`)*
4. Change `MY_TOURIST_ID` to a real ID generated by your website.
5. Flash the code to the Wearable ESP8266.

### Step 3: Flash the Gateway Node
1. Open `Gateway_Node/Gateway_Node.ino`.
2. Edit `WIFI_SSID` and `WIFI_PASS` to match your Mobile Hotspot.
3. Edit `BACKEND_URL` to point to your laptop's Local IP Address. 
   *(To find your laptop's IP, open Command Prompt and type `ipconfig`. Look for IPv4 Address, usually something like `192.168.1.5`. The URL will be `http://192.168.1.5:5000/api/tracking/ping`)*.
4. Flash the code to the Gateway ESP8266.

### Step 4: Test the System!
1. Start your backend (`node server.js`) and frontend (`npm run dev`).
2. Power on the Gateway. Check the Serial Monitor to ensure it connects to your Hotspot.
3. Power on the Wearable and take it outside so the GPS can get a satellite fix.
4. Open the `Live Safety Map` on your website. You should see a green dot appear at the GPS location! Press the SOS button on the Wearable, and the dot will turn red!
